# Contribuindo

1. Abra uma issue antes de mudanças grandes.
2. Commits no padrão Conventional Commits (`feat:`, `fix:`, `docs:`).
3. Toda regra nova em `packages/core/src/rules.ts` precisa de teste em `tests/`.
4. Padrões novos em `rag/patterns/` usam só exemplos genéricos.
5. `npm test` e `npm run typecheck` precisam passar.

Nunca inclua código, dados ou nomes de clientes.
